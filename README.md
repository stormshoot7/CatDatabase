# CatDatabase 🪑🪑🪑
A database of the cats I draw and their accompanying .kra file and any additional details in a .txt file.

# NO AI USED 🖕🤖
That's right, no AI. In fact, I usually put Easter eggs in the .kra files for proof. Check them out!
I swear my writing isn't AI I just like to use emojis in titles 😭😭🙏🙏

# Notes and clarification ℹ️
You can open .kra files using Krita, which you can get by running the install command for your distro.
It should look something like this:

Debian based: sudo apt install krita

Fedora based: sudo dnf install krita

Arch based: sudo pacman -S krita

Android/ChromeOS: not a command, but you can find it on F-Droid

Krita is the art program I use.
